Primeira Aula de Git

Entenda o básico do Git e prepare seu projeto para deploy.

O que você vai aprender

Nesta primeira aula, conheça os conceitos essenciais do Git e comece a versionar seu código.

  • O que é Git: sistema de controle de versão distribuído.
  • Repositório local: como iniciar e organizar seu projeto.
  • Commit: salvar mudanças de forma segura.
  • Branch: criar linhas de desenvolvimento paralelas.
  • Deploy: preparar o projeto para entrega.

Passo a passo

  1. Instalar o Git no seu computador.
    Exemplo: git --version
  2. Inicializar o repositório dentro da pasta do projeto.
    Use: git init
  3. Adicionar arquivos ao controle de versão.
    Use: git add .
  4. Fazer o primeiro commit com uma mensagem clara.
    Use: git commit -m "Primeiro commit - primeira aula de Git"
  5. Verificar o histórico e o estado do repositório.
    Use: git status e git log --oneline

Por que isso importa?

O Git ajuda você a:

  • rastrear alterações no código;
  • voltar a versões anteriores com segurança;
  • colaborar com outros desenvolvedores;
  • manter seu projeto pronto para deploy.

Conteúdo da primeira aula

Vamos partir do básico e avançar para um fluxo simples:

  • Git init
  • Git add
  • Git commit
  • Branch principal
  • Organização do projeto

Esta aula é ideal para começar a usar Git no seu curso de deploy.
